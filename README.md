# 🎓 School Management Dashboard

A full-featured **School Management System** built using:

- **Frontend**: React + Vite + TypeScript + ShadCN UI
- **Backend**: Node.js + Express.js
- **Auth**: JWT-based authentication
- **Data Storage**: In-memory (optional to upgrade later)

---

## ✨ Features

### 🔐 Authentication
- Register & Login with JWT
- Protected API routes

### 🧑‍🏫 Teacher Module
- Create, update, delete teachers
- Filter by department

### 🎓 Student Module
- Manage student records
- Assign departments

### 🗂 Department Module
- CRUD operations for departments

### ⚙ Dashboard UI
- Modern design using ShadCN Components
- DataTable, dialogs, forms & toast notifications
